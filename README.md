# Sakinah

A little space of love and growth, for two. A phone web app for Fatima and Sadiq.

- **Today**: five idea cards a day (Love, Confidence, Sharp Mind, Enterprise, Smile), with a "Try it today" step.
- **Explore**: every idea, grouped into stashes, plus saved ideas.
- **Us**: love level, countdown to the next visit, heartbeats, animated postcards and coupons, today's question, "Who knows me best?", weekly love missions.
- **Chat**: private messages, postcards and shared ideas.
- **Glow**: Fatima's progress, which both can see.

## Files
- `index.html`, `style.css`, `app.js`, `content.js`: the app
- `config.js`: Firebase web settings (empty = preview mode on one phone)
- `fb.js`: Firebase SDK 13.4.0, bundled
- `firestore.rules`: database security rules (paste into Firebase console)
- `sw.js`, `manifest.webmanifest`, icons: home-screen install

Data lives in Sadiq's Firebase project (Google account). Both partners sign in with Google and join with a pairing code.
